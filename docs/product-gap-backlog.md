## Ближайшие инженерные задачи

1. Прогнать PostgreSQL runtime на staging compose, миграции и runtime smoke.
2. Разделить `WarehouseService` на доменные сервисы без изменения бизнес-инвариантов.
3. Ужесточить approval workflow: настройка обязательного утверждения по ролям/типам документов и двухэтапные согласования для ПКУ.
4. Расширить карантинный workflow комиссиями, протоколом проверки, возвратом/утилизацией.
5. Довести ПКУ-контур: строгий регистр, отдельный модал подписи, экспорт PDF/ЭЦП.
6. Добавить serial numbers и расширенный recall dashboard по партиям.
7. Вынести встроенный scheduler в отдельный worker с lock/lease, статусами jobs и мониторингом.
8. Добавить печатную форму и approval workflow для фасовки/переупаковки.
9. Добавить ABC/XYZ scatter-plot и расширенные прогнозные рекомендации.
9. Подключить Redis-backed realtime events через transactional outbox.
10. Доработать frontend в сценарии для простых пользователей: принять, списать, переместить, проверить склад, что требует внимания.
11. Добавить e2e/Playwright smoke tests для ключевых пользовательских сценариев.
12. По датчику CH340 получить от коллеги baud/line ending/скетч или модель датчика; текущая диагностика показывает raw-байты без осмысленных измерений.
