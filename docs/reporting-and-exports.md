# Reporting And Exports

Текущий интерфейс поддерживает CSV-выгрузки для рабочих отчетов. CSV выбран как простой формат, который открывается в Excel и LibreOffice и не требует отдельного сервиса генерации файлов.

## Доступные Экспорты

| Экран | Файл | Содержание |
| --- | --- | --- |
| Главная / Остатки | `sklad-balances.csv` | товар, партия, склад, общий остаток, резерв, свободный остаток, статус, срок годности |
| Документы | `sklad-documents.csv` | номер, тип, статус, склад, количество строк, автор, даты |
| История склада | `sklad-movements.csv` | движение, партия, склад, количество, причина, время |
| Аналитика | `sklad-abc-xyz.csv` | ABC/XYZ, расход, стоимость, свободный остаток, точка заказа, рекомендация |
| Журнал действий | `sklad-audit-log.csv` | время, пользователь, действие, сущность, склад, payload |

## Правила

- Экспорт выгружает строки, которые видит пользователь с учетом текущего поиска и выбранного склада.
- Для ограниченных ролей backend продолжает проверять доступ к складам.
- Чувствительные поля списания не выводятся в обычные read-модели движений.
- CSV не заменяет юридически значимые PDF/ЭДО формы.

## Следующие Отчеты По ТЗ

- Инвентаризационная ведомость для печати с пустой графой "Факт".

- Печатные формы приходных, расходных и возвратных документов.
