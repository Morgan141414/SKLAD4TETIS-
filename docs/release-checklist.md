# Release Checklist

Используйте этот чеклист перед каждым показом заказчику, тестовым запуском или релизом.

## Код И Тесты

- Все изменения закоммичены.
- `python3 -m unittest discover -s tests -v` проходит.
- `node --check frontend/app.js` проходит там, где установлен Node.js.
- Нет незапланированных изменений в `git status --short`.

## Складские Сценарии

- Создание категории, поставщика, склада и товара.
- Приход товара и появление партии в остатках.
- Открытие карточки партии.
- Смена статуса партии: карантин -> доступна -> заблокирована.
- Списание партии.
- FEFO-списание.
- Перемещение между складами/кабинетами.
- Возврат от отделения.
- Возврат поставщику.
- Резервирование и снятие резерва.
- Инвентаризация: старт, ввод факта, проведение, отмена.
- Уведомления по малому остатку и сроку годности.
- ABC/XYZ аналитика.
- CSV-экспорт ключевых отчетов.

## Безопасность

- `SKLAD_DEV_AUTH_ENABLED=false` вне demo.
- JWT secret/issuer/audience заданы для non-demo auth.
- Роли проверены на warehouse scope.
- Ограниченный пользователь не видит и не выполняет действия чужого склада.
- Чувствительные поля списания не отображаются в обычных read responses.

## Эксплуатация

- Health и readiness возвращают ожидаемый статус.
- Создан backup перед релизом.
- Restore-инструкция актуальна.
- Логи приложения доступны.
- Фоновые jobs настроены осознанно.

## Известные Production-Блокеры Полного ТЗ

- PostgreSQL cutover rehearsal на staging: backup, preflight, load, reconciliation, smoke.
- Keycloak/OIDC/JWKS.
- ПКУ-журнал, PDF, двойная подпись и ЭЦП.
- ЭДО/бухгалтерия/закупки.
- Штрихкоды, ценники и ZPL/EPL.
- IoT/термодатчики, логистика, карты, аукционы.
